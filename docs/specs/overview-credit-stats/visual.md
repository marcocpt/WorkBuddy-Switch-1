## 2. 卡片内部布局（单卡）

```text
┌──────────────────────────────┐
│ ① 图标 + 账号名        [当前] │  ← 顶行：provider 图标(14pt)、名称(semibold 12pt)、
│   (次级 11pt: ID 缩写)        │     当前激活时显示「当前」徽标（绿）
│ ② 1,234                       │  ← 主数值：25pt semibold rounded；单位小字
│   总积分                       │
│ ③ 近期到期 · 9/15             │  ← 11pt secondary：始终展示；取「仍有剩余且带到期、
│   256 分将在 9/15 到期         │     到期最近」的一个包；无 → 最近到期/下次结算/暂无可展示
│ ▾ 全部积分包（3）             │  ← 可展开：每行 = 名称 + 剩余/总量 + 进度条 +
│   会员积分  300/400  ▓▓▓▓░░  │     到期（或 7 天内到期/已到期）· 已用 x
│   兑换积分   10/100  ▓░░░░░  │
│ └─────────────────────────────┘
│（加载态：①正常 + ②③ 进度环/占位灰）
│（错误态：①正常 + 红色内联行 "登录已过期，请刷新后重试"）
└──────────────────────────────┘
```

## 3. 状态矩阵

| 状态 | 呈现 |
|---|---|
| 加载中 | 卡片骨架：主数值区显示小号 ProgressView；不闪跳 |
| 有数据 | 按 §2 完整渲染 |
| 单个账号失败（401/超时/格式错） | 主数值区为「—」，红字说明原因；其余卡片正常 |
| Trae 不限量 | 主数值「不限量」，明细行「下次结算 M/D」 |
| Trae 请求计费 | 主数值为请求数，单位「请求」 |
| 无近期到期 | 明细行改为「最近到期 M/D」或「暂无可展示的到期」 |
| 空（无任何保存账号） | 整个积分统计区不渲染（无空态占位） |
| 某客户端无已保存账号 | 该列不渲染（不留空列）；首次加载只给有账号的客户端铺骨架列 |
| 卡片无任何到期信息 | 排在该列末尾（有到期日 → 无到期日 → 拉取失败） |
| 卡片内包明细顺序 | 有效且带日期的包（到期升序）→ 已到期/已用尽 → 无到期日 |

## 4. 设计约束

- 遵循用户偏好：文本控件命中目标 ≥15px（卡片整体可点按范围达标）；中文文案。
- 跟随暗色/亮色主题：使用现有 DesignSystem 色彩 token（OpenUsageColors）与 `controlBackgroundColor` 卡片底、`OpenUsageColors.separator` 描边（与 MetricTile 一致）。
- 三列为等宽列（每列 `maxWidth: .infinity`），列间距 12，卡片间距 10；列头为 12pt semibold secondary（图标 + app 名 + 卡片数）。
- 列内顺序即展示顺序，界面层不做二次排序（排序全部来自 `CreditStatMapper` / `CreditPackageOrdering` 纯函数）。
- 不使用图片资源；无 emoji；系统 SF Symbols 图标。
