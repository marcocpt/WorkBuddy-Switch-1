# 视觉原型：导入 / 导出所有已保存账号

- 版本：v1（未批准草图，等待自检后定版）
- 上游：requirements.md v1、design.md v1
- 适用：macOS 桌面应用（设置页），zh-Hans，亮暗色自适应，随系统外观。

---

## 1. 入口：设置页「账号数据」区

在既有设置页「隐私」区之后新增「账号数据」区，复用既有设置区外观（浅灰底圆角卡片、细分隔描边、分组标题小字）。

```text
┌─ 账号数据 ─────────────────────────────────────────────┐
│  ┌───────────────────────────────────────────────────┐ │
│  │ [ 导出全部账号 ]                                        │ 导出三端已保存的全部账号快照为加密文件。│
│  │                                                     │ 需设置密码；密码无法找回，请妥善保管。    │
│  ├───────────────────────────────────────────────────┤ │
│  │ [ 导入账号 ]                                          │ 从备份文件恢复账号快照。                   │
│  │                                                     │ 已存在的账号将自动跳过，不会被覆盖。        │
│  └───────────────────────────────────────────────────┘ │
└───────────────────────────────────────────────────────┘
```

- 两个按钮等宽大号（controlSize(.large)），左对齐；同区两行纵向堆叠，间距 13pt，与既有设置区一致。
- 图标：导出使用导出样式图标 + 「导出全部账号」；导入使用导入样式图标 + 「导入账号」。
- 进行中：按钮变禁用并内联显示进度指示（旋转小圈），文字保持不变（真实可见可观察状态，满足 UI 证据要求）。

## 2. 导出密码 sheet

```text
┌────────────── 导出全部账号 ──────────────┐
│                                           │
│  备份文件将加密保存。                       │
│  请输入一个密码（至少 8 位）并再次确认。     │
│  密码无法找回，请妥善保管。                 │
│                                           │
│  ☐ 密码：      ＊＊＊＊＊＊＊＊            │
│  ☐ 确认密码：  ＊＊＊＊＊＊＊＊            │
│                                           │
│          [ 取消 ]      [ 继续导出 ]        │
└───────────────────────────────────────────┘
```

- 「继续导出」在 密码满足长度且两次一致 前禁用；不一致/过短时在按钮下方以红色小字显示原因，不打断输入。
- 宽度约 420pt，居中样式与既有重命名 sheet 一致；取消则关闭。

## 3. 导入密码 sheet

```text
┌────────────── 导入账号 ─────────────┐
│                                      │
│  请输入此备份文件的密码：              │
│  ☐ 密码： ＊＊＊＊＊＊＊＊            │
│                                      │
│        [ 取消 ]      [ 导入 ]         │
└──────────────────────────────────────┘
```

- 密码为空时「导入」禁用；确认后进入解密与导入，期间 sheet 关闭并回到设置页显示进度。

## 4. 结果提示（应用级 alert，复用既有弹窗）

| 场景 | 标题 | 文案 |
|---|---|---|
| 导出成功 | 导出完成 | 已导出 N 个账号到所选文件。（若有无快照跳过 S 个则追加说明） |
| 无账号导出 | 无法导出 | 当前没有已保存的账号，请先在各客户端登录并保存账号。 |
| 导出失败 | 导出失败 | 具体原因（磁盘不可写等）。 |
| 导入成功 | 导入完成 | 成功导入 N 个账号，跳过 M 个已存在账号。（失败 K 个时追加原因列表，逐行） |
| 整体失败 | 导入失败 | 密码错误或文件已损坏 / 文件不是本项目备份文件 / 备份版本过高，请升级应用。 |
| 互斥阻断 | 操作被阻止 | 已有账号切换正在进行，请稍后再试。 |

## 5. 空态 / 边界可见性

- 无账号时「导出全部账号」仍可点击但触发上述「无法导出」提示（保留入口，反馈明确）；「导入账号」始终可点击（恢复场景可用）。
- 设置页其他区域视觉不变；新增区在窄窗口下不截断文案（按钮与说明分行）。

## 6. 可达性

- 按钮命中目标不小于 15pt（controlSize(.large) 满足）。
- 密码输入框带「安全（secure）」样式与可读标签（密码 / 确认密码）。
- 进行中与禁用状态对屏幕阅读器可见（禁用语义 + 进度指示 label）。
- 文案全中文；不使用色块单独传达状态（配合文字）。

## 7. 视觉验收锚点（构件一致性）

- 与既有设置区（settingsSection 卡片）视觉一致：controlBackground 底色、separator 描边、8pt 圆角。
- 与既有大按钮（如「保存当前账号」）同款高度与间距。
- 深色模式字体与分隔质量与既有区一致（不引入额外阴影）。
